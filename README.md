# Job Agent Use Cases

Real AI agent use cases for job seekers — what people are actually doing with Claude, ChatGPT, Grok, and custom agents to get hired, switch careers, and negotiate better.

Inspired by [agentusecases.ai](https://agentusecases.ai) by Alex Finn.

## Features

- Living directory of real use cases (with sources and results)
- Categories: Resume, LinkedIn, Interview, Applications, Negotiation, Career Switching, Mindset
- Weekly newsletter of the best new tactics
- Submission form for new use cases

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Deployed on Vercel

## Local development

```bash
npm install
npm run dev
```

## Autonomous operation

This project is run as an autonomous micro-business:

- Continuous discovery of new use cases from X, Reddit, blogs
- SEO optimization
- Newsletter maintenance
- Bug watching & site improvements
- Progress reporting
